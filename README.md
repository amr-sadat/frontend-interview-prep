# 🚀 Frontend Interview Prep

A comprehensive collection of frontend interview questions, answers, explanations, and practical examples — from junior to tech lead level.

## Difficulty Levels

> 🟢 Easy | 🟡 Medium | 🔴 Advanced

Each question is tagged with a difficulty level to help you pace your preparation:

- 🟢 **Easy** — Core fundamentals every frontend developer should know.
- 🟡 **Medium** — Deeper concepts, trade-offs, and practical scenarios.
- 🔴 **Advanced** — Hard system design, performance, and architecture questions.

## Goal

To create a structured frontend interview preparation resource from junior to tech lead level.

## Structure

Each topic contains:

- Interview questions
- Detailed answers
- Examples
- Common follow-up questions
- Real-world scenarios

## How to Use

1. Pick a topic from the [Topics](#topics) table.
2. Answer each question out loud before reading the answer.
3. Write down the questions you struggled with and revisit them later.
4. Follow up on any answer with "why?" — interviewers will.
